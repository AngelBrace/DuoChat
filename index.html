DuoChat 1.0

DuoChat 1.0 is a local window for reading Twitch and YouTube live chat together. You still type in your chat client. This is an interactive mock up of the real app with two fake logs. Click through it the same way you click the app.

Tabs

All mixes both rooms by the clock. Twitch and YouTube each keep one room. Twitch Chat and YouTube Chat are the hidden live pages the app reads. They are not a second copy of the log.

A name

Right-click Won_Won_99 on “IT TASTES LIKE SPACE AND PEPPERONI”. Chat lists only that nickname. Chat Commonalities lists lines that share a useful word. Words opens a Won_Won_99 Words tab. Copy puts that line on the scratch pad.

Words

Right-click taters to pin “what is taters?!”. Click that note. A smaller note appears on tater, and on the slow-mode line, because that line contains tater. A message already on screen is not added again. × on a branch closes that branch. × on the first note, another right-click, or Esc closes the tree.

One person

The Smeagol_Raw_And_Wriggling Words tab can be closed with ×. The main Words tab stays. Turn Common words off on a nickname tab to count every word that person used, including short ones such as “the”.

Saved logs

Setup starts with Save daily logs checked. Open the practice day. The tab reads LogViewer and the date, so it is obvious those rows are a saved file and not the live rooms. × closes that tab. Open folder, in the real app, shows Documents\DuoChat\Logs so a .txt file can be read in another editor.
